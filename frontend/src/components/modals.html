Términos y condiciones

1. Uso de datos e imágenes

Las imágenes y datos de salud se procesan exclusivamente para generar tu diagnóstico. No compartimos ni vendemos tu información a terceros.

2. No sustituye consulta médica

CutisLab es una herramienta de apoyo informativo. No reemplaza el diagnóstico de un dermatólogo certificado.

3. Almacenamiento de datos

Tu historial, imágenes y rutinas se almacenan de forma segura. Puedes eliminar todo en cualquier momento desde tu cuenta.

4. Privacidad

Cumplimos con normativas de protección de datos. No usamos tus imágenes para entrenamiento sin consentimiento explícito.
